# 当前方向（2026-11-06 定）：Twilio / Telnyx 之上的中国本地化通信 console

> 取代「批量 eSIM / 真手机号」作为主线。eSIM 与留学生保号保留为后续可选业务，见 SEGMENT-returning-students.md。

## 一句话定位
给出海的中国商家（跨境电商卖家、外贸、出海 SaaS）用的美国号码与通信后台：中文界面、人民币付款、代办 A2P 合规、国内网络可用。底层号码、通话和短信用 Twilio / Telnyx，我们做的是「壳」和「服务」。

## 不做什么（写死，防止滑向接码平台）
- 不卖「收验证码」，不承诺能接收任何平台的 OTP。
- 不做共享号码、不做匿名注册、不批量卖号。
- 商家必须完成企业实名（营业执照）+ 联系人实名，按账户限制号码数量。
- 入站短信异常模式（大量短码、高频验证码类内容、号码频繁更换）触发风控和人工审核。

## 目标客户（先窄后宽）
1. 跨境电商卖家（Amazon / Shopify / TikTok Shop），需要美国客服电话、售后短信
2. 外贸 / 出海服务公司，需要给海外客户一个本地号码
3. 以后：出海 SaaS、在美华人小商家

## MVP 范围（concierge 起步）
- 号码：搜索并购买美国本地号码，按账户分配
- 通话：网页拨号 + 手机端接听（或转接到中国手机），通话记录、语音信箱、转写
- 短信：网页收发，团队共享收件箱
- 合规：A2P 10DLC 品牌 / 活动注册向导（中文），代填代办
- 计费：人民币预充值 / 月订阅（微信、支付宝），按量计费明细
- 后台：多成员、多号码、权限、审计日志

## 第一周要验证的事（Spike，先验证再写产品代码）
- [ ] **国内网络质量**：在国内（不翻墙 / 翻墙两种条件）用 Twilio Voice SDK 和 Telnyx WebRTC 各打 20 通电话，记录延迟、丢包、接通率。这是最大的技术风险和壁垒
- [ ] **转接到中国手机**的成本和质量（PSTN 外呼到 +86 的费率、来显）
- [ ] **Twilio / Telnyx 转售条款**：ISV 模式要求、终端客户 KYC 义务（Twilio Trust Hub secondary customer profile 等）、中国主体能否开户、哪家对中国客户更友好
- [ ] **A2P 10DLC**：中国注册的公司（无 EIN）能否完成 brand 注册，需要什么材料，审批通过率
- [ ] **成本表**：号码月费、每分钟、每条短信、A2P 费用 → 算出 Quo $15–19/人/月 的价格带下我们的毛利
- [ ] **收款与结汇**：人民币收款、美元付 Twilio 的资金路径（参考 EverHarvest 现有做法）、发票问题

## 第二到四周：手动服务 10 个跨境卖家
- [ ] 找 10 个卖家（朋友圈、跨境卖家群），先用 Twilio 控制台 + 人工帮他们开号、配转接、办 A2P
- [ ] 记录每个人卡在哪、问了什么、愿意付多少、用于沟通还是想收验证码（后者比例高 = 危险信号）
- [ ] 至少 3 个愿意付费续用 → 再写 console

## 竞品对照
- Quo（原 OpenPhone）：$15/人/月起（年付），英文，外币卡
- Google Voice：$10/人/月起，国内需翻墙，需 Workspace
- 国内出海通信云厂商：待调研（谁在做、价格、是否面向小卖家）

## 关键风险
- 国内语音质量不行 → 退化为「短信 + 转接到中国手机」，价值主张变弱
- 上游（Twilio / Telnyx）因终端客户违规封整个账户 → 必须多供应商 + 严格 KYC
- 客户真实需求是收验证码 → VoIP 满足不了，且法律风险高，要坚决不接
