# Roadmap — stage gates

## Gate 0: feasibility (weeks 1–3)
- [ ] Interview 15–20 target users and identify exact legitimate OTP/calling jobs.
- [ ] Send supplier questionnaire to 5+ providers.
- [ ] Obtain written resale and offshore activation terms.
- [ ] Test 3–5 real mobile lines in China; verify device compatibility.
- [ ] Obtain telecom/privacy legal review.
**Exit:** At least one supplier passes all mandatory criteria and tested use cases are sufficiently reliable.

## Gate 1: concierge pilot (weeks 4–6)
- [ ] Manually onboard 20–50 consented users using authorized supplier workflows.
- [ ] Track activation, SMS, voice, refunds, support load and churn signals.
- [ ] Validate willingness to pay and pricing.
**Exit:** Positive contribution after variable costs, manageable support and acceptable reliability.

## Gate 2: mobile self-service MVP (weeks 7–12, contingent)
- [ ] Authentication and tenant model.
- [ ] Plan catalog, billing and carrier adapter.
- [ ] Provisioning status machine and eSIM activation guidance.
- [ ] Number lifecycle, renewals, support and admin audit.
- [ ] Security, anti-abuse and billing reconciliation.

## Gate 3: VoIP feature track (optional)
- [ ] Browser calling, inbound SMS inbox, SIP/Zoiper configuration.
- [ ] A2P compliance and limits for outbound messaging.
- [ ] Multi-number / team management.

## Gate 4: scale
- [ ] Second carrier, automated failover where contractually supported.
- [ ] API/white-label offering and B2B sales.
- [ ] Evaluate carrier-integrated web SMS access and expanded geographies.
