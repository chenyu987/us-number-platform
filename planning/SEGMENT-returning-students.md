# 核心细分：回国留学生「保号」

## 场景
留学生毕业 / 回国，美国号码绑了大量账号（银行、券商、Apple ID、Google、学校、各种 App 的 2FA），中国号码替代不了。现在用的是 T-Mobile / AT&T / Verizon / Mint 等套餐，约 $40/月，回国后基本只为收码和保号，太贵。需求：**便宜地把原号码保留下来，在国内还能收短信。**

## 为什么这个细分可能比原方案好走（待验证）
- **绕开「国内首次激活」难题**：用户人还在美国时，把原号码 port 到便宜运营商（Ultra PayGo / Tello / Red Pocket 等），在美国完成激活，再回国漫游或用 Wi-Fi Calling。
- **号码是用户自己的**：不涉及批量拿卡、转售电话卡，合规风险显著低于原方案；我们卖的是「搬家服务 + 保号运维」。
- **需求明确、痛点有钱可算**：$40/月 → $3–5/月，一年省约 $400+，愿意付一次性服务费的空间清楚。
- **获客精准、有季节性**：毕业季（5–8 月）集中，渠道是 CSSA、小红书、留学生群。

## 风险 / 待挑战的假设
- [ ] DIY 门槛到底多高？知乎 / 小红书已有大量教程，用户为什么要付钱给我们（不懂流程？怕 port 失败丢号？没时间？）
- [ ] 时间窗口：必须在离美前完成 port + 激活；已经回国的用户还能救吗（寄实体卡 + 远程 port-in 是否可行）
- [ ] Port-out 常见坑：家庭套餐（号码在父母 / 室友账户下需要账户持有人配合）、账户号 + 转网 PIN、合约 / 分期手机未结清、手机未解锁
- [ ] 便宜套餐在中国能不能稳定收到短码验证码（银行、券商、Apple、Google 逐个测）
- [ ] 长期不在美国会不会被运营商停号；最低多久要充值 / 使用一次（保号规则）
- [ ] 漫游 vs Wi-Fi Calling：国内无漫游信号时，Wi-Fi Calling 收短信是否稳定、要不要挂梯子
